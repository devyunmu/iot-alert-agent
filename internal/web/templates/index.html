为什么是这个项目

把物联网平台积累的设备接入、告警规则与现场处置经验，封装成 Agent 可直接调用的 MCP 工具，并用评测集量化 LLM 输出质量——这是从平台工程师走向 Agent 平台工程师的能力证明。

  • get_device 读取设备档案
  • summarize_alert 生成分诊建议
  • ack_alert 人工确认闭环
